# Гибка кирпича — розыгрыш для GitHub Pages

## Что внутри
- `index.html` — сама статья (стиль под актуальный Vector 2022)
- `assets/` — фото и видео:
  - `skolk.png` — плакат со станком, "Сколково"
  - `brick-mold.mp4` (+ `mold_poster.jpg` превью) — гибка кирпича на заводе
  - `bouncy.mp4` (+ `bouncy_poster.jpg` превью) — брак, "прыгучий" кирпич

## Как выложить на GitHub Pages
1. Создай репозиторий, например `brick-bending-wiki`.
2. Залей **всю папку целиком** — `index.html` и папку `assets/` со всеми файлами внутри (через Add file → Upload files, перетащи всё разом, GitHub сам разложит по путям).
3. Settings → Pages → Source: ветка `main`, папка `/ (root)` → Save.
4. Через минуту-две сайт будет доступен:
   `https://<твой_логин>.github.io/brick-bending-wiki/`

Видео весят ~3,3–3,4 МБ каждое — это ок для GitHub (лимит на файл 100 МБ, GitHub Pages ограничивает по 1 ГБ на сайт), Git LFS не нужен.

Все ссылки на "Кирпич", "Пластичность", "Клинкерный кирпич" и т.д. в тексте ведут на настоящие статьи ru.wikipedia.org.
