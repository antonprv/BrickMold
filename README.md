# Гибка кирпича — розыгрыш для GitHub Pages

1. Создай новый репозиторий на GitHub, например `brick-bending-wiki`.
2. Залей туда файл `index.html` (можно прямо через веб-интерфейс: Add file → Upload files).
3. В настройках репозитория открой Settings → Pages, в разделе "Source" выбери ветку `main` и папку `/ (root)`, сохрани.
4. Через минуту-две страница будет доступна по адресу вида:
   `https://<твой_логин>.github.io/brick-bending-wiki/`
5. Кинь другу эту ссылку — выглядит как обычная статья Википедии.

Все внутренние ссылки в статье (Кирпич, Пластичность, Клинкерный кирпич и т.д.) ведут на настоящие статьи в ru.wikipedia.org — при клике друг попадёт на реальную Википедию, что добавляет достоверности.
